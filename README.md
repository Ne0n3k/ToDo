# ToDo (SwiftUI + SwiftData)

App created for task management:
- Priorities and deadlines
- Screens: Summary / All / Planned / Overdue / Completed
- Persistence: SwiftData (iOS 17+)

## Requirements
- Xcode 15+
- iOS 17+

## How to run
1. Open the Xcode project.
2. Run on the iPhone simulator.

## Project Standards
- **GitHub Flow** (feature branches → PR → `release` → `main`)
- **CI**: GitHub Actions
- **Quality**: SwiftLint & SwiftFormat
